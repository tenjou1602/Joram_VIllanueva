## Projects

### 1. Student Concern Tracking System

**Problem:** Students had no structured way to file concerns, monitor progress, or tell whether offices were hitting their deadlines.

**Solution:** ConcernTrack — a PHP/MySQL platform with dedicated views for students, department staff, and admins.

**My role:** Sole builder. Handled database design, authentication, routing rules, SLA escalation cron job, audit logs, PDF exports, and a help chatbot with local FAQs plus optional OpenAI support.

**Outcome:** Full tracking from first submission to resolution, with automatic escalation when response targets are missed.

**Stack:** PHP, MySQL, HTML/CSS, JavaScript  
**Link:** https://github.com/tenjou1602/student-concern-tracking

---

### 2. E-Commerce Mobile App

**Problem:** Small sellers needed mobile ordering and sales management — not just a static product page.

**Solution:** A cross-platform Flutter app powered by Firebase Auth and Cloud Firestore.

**My role:** Built sign-up/login, product listings, cart state with Provider, checkout, order history, notifications, and an admin panel for inventory, orders, and live customer chat.

**Outcome:** One codebase serving both a customer storefront and an admin back office.

**Stack:** Flutter, Dart, Firebase Auth, Cloud Firestore, Provider  
**Link:** https://github.com/tenjou1602/flutter303

---

### 3. MotorTrade Inventory Dashboard

**Problem:** Dealership staff were spread across separate spreadsheets for sales, stock, and team activity.

**Solution:** A PHP admin panel that surfaces key metrics and recent transactions in one view.

**My role:** Built summary cards for monthly revenue, inventory totals, active staff, and low-stock warnings, plus SQL-backed tables for the latest sales.

**Outcome:** Managers get sales and inventory insight without digging through files.

**Stack:** PHP, MySQL, HTML/CSS  
**Link:** https://github.com/tenjou1602/motortrade-dashboard
